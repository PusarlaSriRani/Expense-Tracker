# Expense Tracker

## Project Overview

Expense Tracker is a simple web application built using HTML, CSS, and JavaScript. It helps users track their daily expenses, categorize spending, calculate total expenses, and manage records efficiently.

## Features

- Add Expenses
- Delete Expenses
- Category Selection
- Automatic Total Expense Calculation
- User-Friendly Interface
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run using text debugger for better output.
5. Start adding and managing expenses.

## Usage

1. Enter Expense Name.
2. Enter Amount.
3. Select a Category.
4. Click **Add Expense**.
5. View the expense list and total amount.
6. Click **Delete** to remove an expense.
